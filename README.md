# 율곡관 스마트 세탁실

기숙사 세탁기·건조기의 작동 상태와 남은 시간을 조회하는 웹 서비스 프로토타입입니다. 원격 제어 기능은 포함하지 않습니다.

SmartThings API로 세탁기 1대의 상태를 조회하는 테스트를 진행했습니다. 현재 웹 프로토타입은 Sites의 비공개 인증 환경에 의존하며, 기숙사 전체 서비스 운영을 위한 OAuth 갱신·관리자 인증·공유 캐시·기관 API 이용 조건은 추가 검토가 필요합니다.

실제 API 토큰이나 암호화 키는 저장소에 포함하지 않습니다. GitHub에 소스를 저장하는 작업과 웹 서비스 배포는 별개입니다.
